# Runbooks de observabilidade F10

Estes runbooks descrevem diagnóstico local e ações reversíveis. Não contêm credenciais, endpoints autenticados, comandos destrutivos, paging ou procedimentos de produção.

Procedimento comum: confirmar o código agregado, consultar diagnóstico interno autorizado, preservar F5/F7, interromper qualquer reparação não determinística e validar recuperação por health e testes focados.
